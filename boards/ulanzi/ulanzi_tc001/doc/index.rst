.. zephyr:board:: ulanzi_tc001

Overview
********

The Ulanzi TC001 is a desktop smart pixel clock built around an ESP32-WROOM-32D module.
It features an 8x32 RGB LED matrix, three buttons, a buzzer, an ambient light sensor, a
real-time clock, a temperature and humidity sensor, and a built-in rechargeable battery.
The board is programmed over its USB-C port through an on-board CH340 USB-to-UART bridge.

Hardware
********

.. include:: ../../../espressif/common/soc-esp32-features.rst
   :start-after: espressif-soc-esp32-features

The board integrates the following components:

- 8x32 matrix of 256 daisy-chained WS2812B-Mini RGB LEDs, connected to GPIO32
- Three user buttons (left, middle, right), active low, connected to GPIO26, GPIO27 and GPIO14
- Passive piezo buzzer, connected to GPIO15
- GL5516 photoresistor for ambient light sensing, connected to GPIO35 (ADC1 channel 7)
- Battery voltage sense through a resistor divider, connected to GPIO34 (ADC1 channel 6)
- DS1307 real-time clock at I2C address ``0x68``
- SHT3x temperature and humidity sensor at I2C address ``0x44``
- CH340 USB-to-UART bridge, connected to UART0

Both I2C devices share the bus on GPIO21 (SDA) and GPIO22 (SCL).

Supported Features
==================

.. zephyr:board-supported-hw::

The LED matrix is exposed as a display through the ``led-strip-matrix`` driver on top of a
``worldsemi,ws2812-spi`` LED strip. The WS2812B data line is generated by the SPI2 controller
on GPIO32.
