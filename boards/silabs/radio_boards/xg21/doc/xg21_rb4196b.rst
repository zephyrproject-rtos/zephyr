Overview
********

The `EFR32xG21B +20 dBm Radio Board`_ is the radio board delivered with the
`EFR32xG21 Pro Kit +20 dBm`_, and is also available standalone. It contains a Wireless
System-On-Chip from the EFR32MG21B family built on an ARM Cortex®-M33 processor with excellent low
power capabilities.

The radio board plugs into the Wireless Pro Kit Mainboard BRD4002A and is supported in Zephyr as one
of several :ref:`silabs_radio_boards`.

.. _EFR32xG21B +20 dBm Radio Board:
   https://www.silabs.com/development-tools/wireless/xg21-rb4196b-efr32xg21-wireless-20-dbm-radio-board
.. _EFR32xG21 Pro Kit +20 dBm:
   https://www.silabs.com/development-tools/wireless/efr32xg21-pro-kit-20-dbm

Hardware
********

- EFR32MG21B020F1024IM32 Mighty Gecko SoC
- CPU core: ARM Cortex®-M33 with FPU
- Flash memory: 1024 kB
- RAM: 96 kB
- Transmit power: up to +20 dBm
- Operation frequency: 2.4 GHz
- Inverted-F PCB antenna
- Crystals for LFXO (32.768 kHz) and HFXO (38.4 MHz).

For more information about the EFR32MG21 SoC and BRD4196B board, refer to these
documents:

- `EFR32MG21 Website`_
- `EFR32MG21 Datasheet`_
- `EFR32xG21 Reference Manual`_
- `BRD4196B User Guide`_

+------+---------------+----------------------------------+
| PA6  | USART0_RX     | Virtual COM port receive         |
+------+---------------+----------------------------------+
| PB0  | GPIO          | Push button 0                    |
+------+---------------+----------------------------------+
| PB1  | GPIO          | Push button 1                    |
+------+---------------+----------------------------------+
| PC0  | USART2_TX     | Display serial data              |
+------+---------------+----------------------------------+
| PC2  | USART2_CLK    | Display serial clock             |
+------+---------------+----------------------------------+
| PC3  | GPIO          | Display chip select              |
+------+---------------+----------------------------------+

+------+---------------+----------------------------------+
| PC5  | PTI_DFRAME    | Packet Trace Interface frame     |

System Clock
============

The EFR32MG21B SoC is configured to use the HFRCODPLL oscillator at 80 MHz as the system clock,
locked to the 38.4 MHz external crystal oscillator on the board.

Serial Port
===========

The EFR32MG21B SoC has three USARTs.
USART0 is connected to the board controller and is used for the console.

Flashing
========

Connect the BRD4002A board with a mounted BRD4196B radio board to your host
computer using the USB port.

Here is an example for the :zephyr:code-sample:`hello_world` application.

.. zephyr-app-commands::
   :zephyr-app: samples/hello_world
   :board: xg21_rb4196b
   :goals: flash

Open a serial terminal (minicom, putty, etc.) with the following settings:

- Speed: 115200
- Data: 8 bits
- Parity: None
- Stop bits: 1

Reset the board and you should see the following message in the terminal:

.. code-block:: console

   Hello World! xg21_rb4196b

Bluetooth
=========

To use Bluetooth functionality, run the command below to retrieve necessary binary
blobs from the Silicon Labs HAL repository.

.. code-block:: console

   west blobs fetch hal_silabs

Then build the Zephyr kernel and a Bluetooth sample with the following
command. The :zephyr:code-sample:`bluetooth_observer` sample application is used in
this example.

   :zephyr-app: samples/bluetooth/observer
   :board: xg21_rb4196b
