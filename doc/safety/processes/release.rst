Process
*******

Purpose & Scope
===============

The release process aims at moving software lifecycle development artefacts from development into production.

This process is based on the established `Release Process <https://docs.zephyrproject.org/latest/project/release_process.html>`_ which defines the scope of the release and its timeline. 

This process is applicable to Zephyr project safety releases and applies to all of the software life cycle data, software tools and hardware tools produced and used throughout the development life cycle.

Activities
==========

Artefacts are released through the CM tool as documented in `Contribution Guidelines <https://docs.zephyrproject.org/latest/contribute/guidelines.html#pull-request-guidelines>`_.

A complete release is performed as defined in `Release Process <https://docs.zephyrproject.org/latest/project/release_process.html>`_.
