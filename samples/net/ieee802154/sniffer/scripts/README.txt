Wireshark extcap plugin for the IEEE 802.15.4 sniffer sample.

ieee802154_sniffer.py parses the capture lines the sample prints on its
console and works with any radio driver the sample runs on.

Firmware, build instructions and installation instructions:
samples/net/ieee802154/sniffer/
