Wireshark extcap plugins for the IEEE 802.15.4 sniffer sample.

Each vendor whose radio driver supports the sniffer sample can add its
own extcap plugin to this directory, one script per plugin.

Firmware, build instructions and installation instructions:
samples/net/ieee802154/sniffer/
